Clip Manager

Drop in your Tricking 0 clips. This generates a thumbnail and detects horizontal/vertical for each one automatically, then builds the clips.json file the gallery reads from — no manual editing needed. Everything happens in your browser; nothing is uploaded anywhere.

📹

Drag & drop clips here, or click to browse.
Any number of horizontal or vertical .mp4/.mov files.

How to use what this generates

  1. Drop your clips above and add an optional caption for each.
  2. Click "Generate" — it downloads a .jpg thumbnail per clip plus one clips.json file.
  3. Upload the original video files, the downloaded thumbnail images, and clips.json into the assets/ folder of your site repo (drag them into GitHub's "Add file → Upload files" page is the easiest way).
  4. Make sure clips.json overwrites the old one. Refresh the site — your clips show up automatically, no code edits.
